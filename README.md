# Обучение змейки с помощью нейроэволюции

Данный проект представляет собой самообучающуюся систему на основе искусственного интеллекта, которая учится играть в классическую игру «Змейка» без помощи человека и заранее заготовленных правил поведения.

В проекте демонстрируется концепция **нейроэволюции (Neuroevolution)** — подхода, объединяющего искусственные нейронные сети и генетические алгоритмы для имитации процесса естественного отбора по Чарльзу Дарвину.

---

## 📌 Суть проекта

В отличие от традиционного программирования, где логика описывается жесткими условиями (например, `if apple_is_left: move_left()`), в данном проекте змейка изначально **абсолютно ничего не знает о мире**. В первом поколении все агенты движутся хаотично, совершают нелепые круговые движения, врезаются в стены и мгновенно погибают.

Суть проекта — запустить конвейер эволюции:

1. **Слепой поиск:** Случайные мутации создают сотни разных вариантов «мозгов».
2. **Жестокий отбор:** Те змейки, которые случайно повернули в сторону яблока или прожили на пару секунд дольше, получают высокий балл приспособленности ($Fitness$).
3. **Передача опыта:** Алгоритм берёт за основу структуру мозга лучших агентов, скрещивает их параметры и добавляет новые мутации для поиска еще более эффективных стратегий навигации.

По мере смены сотен поколений у агентов **эволюционно формируются сложные паттерны поведения**: сначала они учатся избегать стен, затем целенаправленно преследовать еду, а на поздних этапах — продвинутой навигации (например, закручиваться в спираль и не блокировать собственное тело при максимальном увеличении длины хвоста).

## 🧠 Архитектура «Мозга» (Нейросети)

Каждая змейка обладает собственным мозгом в виде полносвязной нейронной сети (многослойного перцептрона):

- **Входной слой:** 20 нейронов (информация об окружении).
- **Скрытые слои:** 2 скрытых слоя по 18 нейронов в каждом.
- **Выходной слой:** 4 нейрона (направления движения: вверх, вниз, влево, вправо).

В качестве функции активации нейронов для скрытых и выходного слоев используется сигмоида: $$\sigma(x) = \frac{1}{1 + e^{-x}}$$

### Входные данные («Зрение» змейки)

Массив входных данных состоит из 20 значений, которые рассчитываются по принципу обратного расстояния до объекта, чтобы более близкие объекты давали более сильный сигнал: $$Input_i = \frac{1}{d_i}$$ где $d_i$ — это дистанция (в клетках) по заданному направлению до:

- Границ поля (по 8 направлениям, включая диагонали).
- Собственного хвоста (по 8 направлениям).
- Яблока/еды (по 4 базовым направлениям).

## 🧬 Алгоритм работы генетического алгоритма

Обучение происходит циклически и состоит из следующих последовательных шагов:

### Шаг 1. Инициализация популяции

В начале симуляции создается стартовая популяция из 200 независимых змеек (`pop_size=200`). Веса матриц нейросети для каждой змейки инициализируются случайными числами в диапазоне от -1 до 1.

### Шаг 2. Жизненный цикл и оценка

Каждая змейка "проживает" свою жизнь на игровом поле. Шаг за шагом она собирает данные о среде через свои датчики и передает их в нейросеть для принятия решения о следующем повороте. Жизнь змейки заканчивается, если она врезается в стену, собственное тело или у нее заканчивается запас энергии (`time_to_live`), который пополняется при съедании яблок.

### Шаг 3. Подсчет приспособленности (Fitness)

Когда все змейки в поколении погибают, алгоритм оценивает их успешность. Функция приспособленности ($Fitness$) строго вознаграждает змеек за съеденные яблоки (возводя это число в куб) и слегка поощряет время выживания:

$$Fitness = L + S^3 \times 100$$

Где:

- $L$ (`life_time`) — количество шагов, которые змейка успела сделать.
- $S$ (`score`) — количество съеденной еды.

### Шаг 4. Селекция (Отбор родителей)

Для создания следующего поколения из текущего отбираются лучшие представители:

1. **Элитизм:** 2 лучшие змейки с самым высоким Fitness переходят в следующее поколение в неизменном виде (клонируются). Это гарантирует стабильное сохранение лучших найденных решений.
2. **Рулеточный отбор (Roulette Wheel Selection):** Для заполнения оставшихся 198 мест выбираются пары родителей. Шанс змейки стать родителем прямо пропорционален её Fitness. Суммируется фитнес всей популяции, генерируется случайное число, и алгоритм накапливает сумму фитнесов по списку, пока не превысит это число.

### Шаг 5. Скрещивание (Crossover)

Получив двух родителей, алгоритм формирует потомка, комбинируя матрицы их весов (`whi`, `whh`, `woh`). Скрещивание реализовано как двумерное одноточечное:

- Случайным образом выбираются индексы строки и столбца матрицы.
- Все веса матриц до этой "точки" берутся от первого родителя, а все веса после — от второго.

### Шаг 6. Мутация (Mutation)

Чтобы поддерживать генетическое разнообразие и не дать алгоритму застрять в локальном минимуме, гены потомков подвергаются мутации. С вероятностью 1% (`mutation_rate = 0.01`) каждый отдельный вес может измениться. К текущему весу прибавляется значение, взятое из нормального (гауссовского) распределения, после чего результат жестко ограничивается (clamped) в диапазоне $[-1; 1]$:

$$w_{new} = \max(-1, \min(1, w_{old} + \mathcal{N}(0, 1)))$$

Где $\mathcal{N}(0, 1)$ — случайное число из стандартного нормального распределения со средним 0 и стандартным отклонением 1.

## 🚀 Структура проекта

- `main.py` — Точка входа. Содержит настройку гиперпараметров и переключение между ручным режимом игры и режимом обучения ИИ.
- `World.py` — Контроллер симуляции: управляет поколениями, шагами ГА и запускает демонстрацию обученного чемпиона.
- `Population.py` — Менеджер популяции агентов: отвечает за селекцию, подсчет общего фитнеса и запуск репродукции.
- `Snake.py` — Логика поведения змейки, расчет ее "зрения" (входного вектора) и функции приспособленности.
- `Perceptron.py` — Реализация многослойного перцептрона (прямой проход сигнала, применение функций активации).
- `Matrix.py` — Математическое ядро: операции над матрицами, функции активации, мутация матриц и кроссовер.
- `Field.py` & `Food.py` — Игровая среда, отрисовка графики через Pygame и генерация еды.
- `plot_stats.py` - Построение графиков, где по горизонтали номер поколения, а по вертикали - различные характеристики: масимальное значение фитнеса поколения, срднее значение финтеса поколения и максимальное количество съеденных яблок за поколение
